# HS Certify Pro — 배포 저장소

한서대학교 **개인화 대학기관평가인증 사전검증 프로그램**의 설치본을 배포하는 곳입니다.

- 앱이 켜질 때 이곳의 최신 릴리스를 확인하고, 새 판이 있으면 받아서 다음 실행에 적용합니다.
- 소스 코드는 올라가지 않습니다. 릴리스에 설치본(.exe)과 매니페스트(latest.yml)만 둡니다.
- 보고서·증빙·확정본 기준선 등 대학 내부 자료는 설치본에 포함되지 않습니다.

## 설치

[Releases](../../releases) 에서 최신  를 내려받아 실행하십시오.
